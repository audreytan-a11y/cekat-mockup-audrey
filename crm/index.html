FAQ

Questions, answered.

Do I have to add contacts by hand?

No. Every customer interaction automatically generates a CRM card, so there’s no manual input.

Can I run more than one board?

Yes. Create separate boards for Deals, Leads or Projects, or start from a blank template. You can set each board to public or restricted.

Can I see my customers as a list?

Yes. Switch between Kanban View, organized by status, and a compact List View.

Who can see what?

Administrators see and edit all boards. Basic roles see only their own board. You can also set up manager and subordinate hierarchies and turn peer data sharing on or off.

Can I add my own fields?

Yes. Add custom fields like text, date and dropdown, and arrange the layout to match your workflow.
